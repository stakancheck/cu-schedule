# Свободные аудитории ЦУ

Интерактивный план кампуса со статусами аудиторий и расписанием на день.

## Запуск

```bash
python3 -m http.server 8765
```

Открыть http://localhost:8765. Без сервера (через `file://`) браузер не загрузит скрипты.

Онлайн-версия: https://stakancheck.github.io/cu-schedule/

## Обновление расписания

Автоматически: GitHub Actions (`.github/workflows/update-schedule.yml`) каждую ночь в 02:30 МСК
скачивает выгрузку с [cu-schedule.ru](https://cu-schedule.ru/) (та же, что «Скачать Excel -> Списком ->
Всё расписание»), и если файл изменился, пересобирает базу, коммитит и пересобирает Pages.
Запустить вручную: вкладка Actions -> «Обновление расписания» -> Run workflow.

Вручную локально:

```bash
python3 scripts/update.py
```

Или из своего xlsx:

```bash
python3 scripts/build_db.py raspisanie-spiskom.xlsx
```

## Обновить план Дуката

План парсится из PDF (векторы стен и иконок, контуры аудиторий через сегментацию):

```bash
python3 scripts/parse_ducat.py ~/Downloads/plan-ducat.pdf
```

Нужны `pymupdf`, `opencv-python`, `numpy`.

## Структура

- `scripts/update.py` - скачивает свежий xlsx и пересобирает базу, если он изменился.
- `scripts/build_db.py` - парсер xlsx (листы по неделям).
- `data/schedule.csv` - полная база: одна строка на занятие, аудитории через `;`, дубли из исходника убраны.
- `data/rooms.csv` - справочник аудиторий (кампус, этаж, число занятий).
- `data/schedule.js` - компактная база для приложения.
- `js/plans.js` - геометрия этажей ЦТ (координаты сняты со скриншотов планов).
- `scripts/parse_ducat.py` - парсер PDF-плана Дуката.
- `js/plans-ducat.js` - сгенерированная геометрия 10 этажей Дуката, руками не править.
- `js/app.js`, `css/app.css`, `index.html` - интерфейс.

## Управление

- Клик по аудитории: фильтр расписания, окна свободного времени. Esc сбрасывает выбор.
- Стрелки влево/вправо: день назад/вперёд. Цифры: этаж (0 = 10 этаж). R: повернуть план.
- Колесо или щипок: масштаб, перетаскивание: сдвиг плана.
- Состояние (этаж, дата, время, аудитория, поворот) хранится в адресе, ссылкой можно поделиться.
